# MYBudgyH

MYBudgyH is a full‑stack expense tracker web app. The frontend is built with React + Vite and styled with Tailwind CSS. The backend is an Express + Node API and MongoDB (via Mongoose) is used for persistence.

Tech stack

- Frontend: React 19, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB (Mongoose)
- HTTP client: Axios
- Auth: JSON Web Tokens (JWT), bcrypt for password hashing
- Charts: Recharts

Features

- Add, edit, and delete expenses
- Categorize expenses (e.g., Food, Transport, Bills)
- Per-category breakdowns and charts
- Filter expenses by date or category
- User authentication and per-user data

Live: https://my-budgy-h.vercel.app/
