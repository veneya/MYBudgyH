# MYBudgyH

MYBudgyH is a simple, lightweight expense tracker web app built with JavaScript, HTML, and CSS. It helps you record, categorize, and review your expenses so you can keep better track of your personal finances.

## Features

- Add, edit, and delete expenses
- Assign categories to expenses (e.g., Food, Transport, Bills)
- View total spending and per-category breakdowns
- Filter expenses by date or category
- Export expense data as CSV (if implemented)

## Quick start

1. Clone the repository:

   git clone https://github.com/veneya/MYBudgyH.git

2. Open the app

- If the project is a static site, open `index.html` in your browser, or serve the directory with a simple HTTP server (recommended):

  - Using Python 3: `python -m http.server 8000` then open `http://localhost:8000`
  - Using Node (http-server): `npx http-server .`

- If the project includes a Node.js-based build (check for `package.json`), run:

  npm install
  npm start

3. Add an expense: use the UI to enter an amount, category, date, and optional notes.
